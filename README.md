## Moving

The API is the same. Change the package reference and the namespace to `CommunityToolkit.VectorData.Chroma`. The [package README](src/ChromaDB.VectorData/README.md) shows the commands.

## History

A [Chroma](https://www.trychroma.com/) provider for [Microsoft.Extensions.VectorData](https://learn.microsoft.com/dotnet/ai/vector-stores/overview), built on [ChromaDotNet.Client](https://github.com/ChromaDotNet/ChromaDB.Client), published from 0.1.0 to 0.4.4. It started as a copy of the Qdrant provider in [CommunityToolkit/AI](https://github.com/CommunityToolkit/AI), under the MIT license. The AI Community Toolkit accepted it in [CommunityToolkit/AI#58](https://github.com/CommunityToolkit/AI/pull/58).
